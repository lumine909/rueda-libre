¿Quienes Somos?

¿que buscamos?

Somos una organizacion que busca una mejor movilidad para las personas, pudiendo transportarse de manera mucho mas facil por la ciudad de manera que lleguen mas rapido a su destino.

¿Como Alquilar?

Proceso de Alquiler

Para alquilar una bicicleta, solo debes ingresar a nuestro sitio web y seleccionar la bicicleta que deseas alquilar, luego debes llenar un formulario con tus datos personales y realizar el pago correspondiente. Una vez confirmado el pago, recibirás un correo electrónico con la confirmación de tu alquiler y las instrucciones para recoger tu bicicleta.
