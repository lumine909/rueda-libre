¿Como Alquilar?

Proceso de Alquiler

Para alquilar una bicicleta, solo debes ingresar a nuestro sitio web y seleccionar la bicicleta que deseas alquilar, luego debes llenar un formulario con tus datos personales y realizar el pago correspondiente. Una vez confirmado el pago, recibirás un correo electronico con la confirmación de tu alquiler y las instrucciones para recoger tu bicicleta.
